# EREAN — Kinetic Portfolio

A dual-axis interactive kinetic web portfolio crafted with vanilla HTML5, CSS3, and GSAP 3 (ScrollTrigger).

## Features
- **Dual-Axis Trajectory**: Seamlessly transitions between a pinned horizontal scrolling track and smooth vertical viewport extensions.
- **Section 1 (Hero)**: Sequential line drawing of directional arrows coupled with kinetic typography choreography for `EREAN`.
- **Section 2 (Editorial)**: Character-by-character masking wave reveal with proportional graphic blocks and baseline alignment.
- **Fullscreen Navigation**: Adaptive monochromatic menu overlay with mouse-following lagging card preview.
- **Fully Responsive**: Fluid `clamp()` scale matrix calibrated across desktop, tablet, and mobile displays.

## Tech Stack
- **Framework**: Vite
- **Animation**: GSAP 3 + ScrollTrigger
- **Typography**: Google Sans / Open Sans
- **Styling**: Modern CSS3 (CSS Custom Properties, Flexbox)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
